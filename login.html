로그인 (카카오 소셜 로그인)

1. 카카오 로그인 시작

아이디/비밀번호 회원가입 없음 — 카카오 로그인만 지원 (기획서 3.1절)

2. 카카오 콜백 → User 자동 생성/조회 → JWT 발급

kakaoId 기준으로 User가 없으면 생성, 있으면 조회. 이후 Access/Refresh JWT 발급.

참고

    

      이 목업에서는 실제 카카오 인증을 하지 않고, 상단 "현재 로그인" 셀렉트로 고른 유저로 바로 로그인된 것처럼 시뮬레이션합니다.

      실제 구현에서는 /oauth2/authorization/kakao → 카카오 동의화면 → /login/oauth2/code/kakao 콜백 순서입니다.
