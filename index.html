GoodsBridge 뷰단 목업

이 사이트는 실제 백엔드가 없는 클릭 가능한 화면 목업입니다. 모든 데이터는 localStorage에만 저장되며, 버튼을 누르면 실제로 발생할 API 호출을 우측 하단 "API 호출 로그"에 시뮬레이션으로 표시합니다.
목적: 개발 착수 전에 화면 흐름을 먼저 눌러보면서 기획서/이슈에 빠진 기능이 있는지 미리 발견하는 것.

어떻게 쓰면 되나요

  1. 상단 "현재 로그인" 셀렉트로 유저A / 유저B / 가게주인 / 관리자를 바꿔가며 각 화면을 눌러보세요 (교환·체크인·승인 등은 역할에 따라 결과가 다릅니다).
  2. 각 페이지 상단의 #번호 배지는 그 화면이 어느 GitHub 이슈에 대응하는지 보여줍니다.
  3. 진행하다가 "이거 화면/기능이 있어야 할 것 같은데 안 보이네?" 싶은 게 있으면 빠진기능 체크 페이지에 적어둔 후보 목록과 비교해보세요.
